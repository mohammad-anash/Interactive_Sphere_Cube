
# Interactive Sphere & Cube

An interactive 3D experience built with Three.js, exploring 3D objects and real-time interaction in the browser.

## Features

- Interactive 3D sphere and cube
- Real-time 3D rendering with Three.js
- Browser-based experience
- Built with JavaScript and WebGL
- raycaster with mouse pointers
- random HSL Color

## Tech Stack

- Three.js
- JavaScript
- HTML
- CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/mohammad-anash/Interactive_Sphere_Cube
```

Install dependencies:

```bash
npm install
```

Start the development server using the command defined in `package.json`.
